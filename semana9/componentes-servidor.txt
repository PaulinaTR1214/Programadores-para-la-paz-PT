Sistema operativo:
Es el software principal que administra los recursos del computador o servidor. Permite ejecutar aplicaciones y gestionar archivos, memoria y procesos.

Node.js:
Es un entorno de ejecución que permite ejecutar JavaScript en el servidor. Facilita la creación de aplicaciones y APIs.

Aplicación server.js:
Es el archivo que contiene el código del servidor. Define las rutas y las respuestas que reciben los usuarios.

Puerto:
Es el punto de comunicación que utiliza el servidor para recibir solicitudes. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros que almacenan información sobre la actividad del servidor. Ayudan a detectar errores y monitorear el funcionamiento del sistema.
