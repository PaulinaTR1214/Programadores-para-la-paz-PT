Al enviar una petición POST a la ruta /registro con el JSON:

{
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

el servidor responde con:

{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

Esto confirma que el servidor recibió correctamente los datos enviados y los devolvió en formato JSON.
